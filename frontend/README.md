# CatDog Vision Classifier - Frontend

## Overview
Web interface for the CatDog Vision Classifier application.

## Tech Stack
- **Framework**: React/Vanilla JS
- **Styling**: CSS/Tailwind
- **HTTP Client**: Fetch API/Axios

## Setup

```bash
cd frontend
npm install
```

## Running

```bash
npm start
```
