# CatDog Vision Classifier - Frontend Source

## Overview
Frontend source code for the CatDog Vision Classifier application.

## Project Structure

```
frontend/src/
├── components/
│   ├── UploadForm.js
│   ├── ResultDisplay.js
│   └── LoadingSpinner.js
├── pages/
│   └── Home.js
└── utils/
    └── api.js
```

## Files

### components/UploadForm.js
Image upload form component.

### components/ResultDisplay.js
Result display component with confidence scores.

### components/LoadingSpinner.js
Loading indicator component.

### pages/Home.js
Main application page.

### utils/api.js
API communication utilities.
